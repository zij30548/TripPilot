## 使用与数据流

1. 正式首页或事务式需求编辑中选择当前六城之一，点击“从照片发现必去地点”。/demo不接入此入口。
2. 选文件只创建本地Object URL预览，明确告知点击后会发送到千问。主动“识别照片”才发一个二进制请求；没有文件名、图片URL、城市答案提示或期望答案传给模型。
3. `POST /media/landmark?destination_id=…&request_id=…` 校验闭合目的地和请求身份→有界读取→内存解码／转正／清除元数据／缩小→一次视觉请求→严格输出校验。`photo-landmark-v1` 回显请求和目的地，最多3条`name/city/basis`，状态为possible/uncertain/unrecognized，不含POI ID、坐标或可执行动作。
4. 线索城市必须精确匹配共享六城展示名／官方名，才可“用此线索准备搜索”。城市未知、其他城或不支持城阻止该入口；不自动切城或把同名地点套到本城。城市表达不能唯一识别时提示普通手动搜索。
5. 复用 `RequirementPlacePicker`：选线索不发高德请求，再点击搜索／按回车才调用既有搜索；点候选只预览，明确确认后将高德返回的ID、坐标、地址、类别、来源、归属写入编辑中的必去。按ID去重、最多6个；模型线索不能直接转Place。
6. 取消整次需求编辑保留原草案、费用和地图；确认后沿用原失效规则，主动生成才查询路线。照片不进入候选池、存档或模型行程快照，saved-trip-v3无新增版本／字段。

照片、选择器会话及请求使用AbortController＋单调版本；更换文件（含同文件重选）、切城、关闭、取消编辑、卸载同步失效，旧success/error/finally不能写回。Object URL更换／关闭／卸载释放；搜索组件置于需求form之外，不嵌套form或让搜索Enter生成行程。

## 资源、隐私与配置

- 实际内容只允许JPEG、PNG、静态WebP；5MiB二进制上限在完整解码前逐块检查；20,000,000像素，动画／多帧／损坏／伪格式拒绝。读取阶段10秒，单进程同时接收／解码／识别1张，忙时429无排队。Pillow12.3.0为唯一新依赖，已锁定，未升级原依赖。
- EXIF方向先应用，再缩至长边≤2048，在新RGB画布上转JPEG；不保留EXIF／ICC／注释。内存BytesIO，不使用multipart临时文件、不落地用户照片、不接受任意URL。正常结束／失败释放引用；取消解码需等待有界像素任务清理，不能声称精确硬实时结束。浏览器本地预览不是经过服务端像素检查的图片，最终以上传内容检查为准。
- 独立 `QWEN_VISION_MODEL=qwen3-vl-plus`，复用后端 `QWEN_API_KEY`（SecretStr）与北京白名单 `QWEN_BASE_URL`，绝不接受前端模型／URL／Key。`QWEN_MODEL`及三项行程AI不改。只更新 `.env.example`占位／非敏感模型名，**未覆盖本机.env**。地址和TLS／无重定向规则复用原适配器。
- 本轮核对[视觉模型](https://help.aliyun.com/zh/model-studio/qwen3-vl-plus)、[视觉理解](https://help.aliyun.com/zh/model-studio/vision)及[结构化输出](https://help.aliyun.com/zh/model-studio/qwen-structured-output)官方说明：VL列入JSON Object支持，不能冒称采用文档未列支持的strict JSON Schema。固定JSON Object＋提示中的Schema＋服务端Pydantic严格校验；拒绝额外字段、错误类型、过长／过多／重复线索、矛盾状态、工具调用、拒绝、截断和空输出。未放宽既有文本AI解析器。
- 非思考、非流式、max_tokens1024，单次模型整体20秒、connect5秒、输入7MiB／响应32KiB；前端35秒（上传10＋模型20＋余量）。不重试、不调用工具／联网搜索、不换模型。取消等待不保证上游停计费。

- 日志不记录图像、Base64、认证头、完整请求或原始网络响应。本轮公开许可样本单独保存在仓库外，仅为验收资产，不是产品用户图片持久化。并发保护只是单进程资源上限，不是多实例／账号限流；公网开放仍缺鉴权、配额与隔离。
