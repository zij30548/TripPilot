# TripPilot：3～5 分钟演示脚本

使用生产前端 `http://localhost:3000/` 与已有后端。真实服务可能超时；失败时解释错误，不使用示例冒充成功。演示用费用均为用户估算。本轮千问新增额度为 0，演示只介绍 AI 入口，不点击调用。

## 0:00–0:50　确认需求，不是生成行程

首页填上海 1 天、2 人、总预算 3000 元、09:00–18:00。搜索“静安寺”，核对地址并确认住宿参考点；搜索“武康大楼”并明确确认必去。住宿参考点不是酒店预订。

点击“确认需求，开始规划”。指出：已经进入正式工作区，但还没有草案。没有调用旧 Mock 计划，也没有自动搜索候选、查询交通、天气或 AI。有必去地点时可以直接生成，无需先准备候选。

## 0:50–1:40　主动生成真实草案

在“生成与查看草案”核对停留 60 分钟和午餐 12:00–13:00，主动点击生成。

展示实际返回的步行秒数、向上取整的分钟、访问与住宿返程。不要照读一个固定到达时间，必须以本次结果为准。

点击“查看当天地图”，展示真实高德底图：住是住宿参考点，1、2… 对应当天实际访问顺序。点时间轴的“在地图查看”定位标记，再点景点标记回到访问卡片；“查看当天全部地点”恢复全览。切日时地图与时间轴同步，空日期没有地点标记。首次打开会加载地图 SDK 和底图，定位操作不额外查询业务数据。

在一个实际交通条目点击“查看这段路线”，展示生成草案时同一次查询的道路几何，再选择返程，对照起终点、查询时间和秒数。一次只选一段，不拼接全天路线；数字仍是访问顺序。地点定位保留折线，“查看这段路线全貌”恢复视野，“清除路线”只清理地图选择。公交的蓝色虚线为接驳步行、紫色实线为公交、粉色实线为地铁，以实际返回为准；没有几何或超限时明确提示，不补查、不连直线、不改变可保存草案。

说明分工：高德提供地点与交通参考；确定性规则按必去顺序、每日窗口、停留、午餐和返程约束排程。默认停留来自规划设置，不是高德游玩时长。若部分未安排，展示原因，不能宣称全部完成。

## 1:40–2:30　核对费用，可选功能不是前置条件

进入“核对、调整与保存”，填示范性的全程住宿 500、当日餐饮 100、其他 0，门票先留空。说明未知不能当零；按每次实际交通计费，估算不会改变排程。

折叠再用导航展开，确认草案和费用还在。可说明天气需主动查询；AI 仅解释当前事实或理解“排除一个已安排可选地点”的受限意图，不生成交通数据，不负责整份排程。本轮不调用模型。

如需展示调整，可事先主动获取候选、再生成含可选地点的草案。预览不改原方案，取消保留，只有明确采用才更新；不同查询批次的变化不一定全由排除造成。这段可省略，天气和 AI 都不是保存条件。

## 2:30–3:15　保存当前正式草案

填写短名称，点击“保存当前正式草案”，等待服务端确认。打开历史列表与只读详情：展示保存时间、原生成时间与路线查询时间。

说明保存的是一致快照，不是自动保存。未采用的调整预览不入库；结果不确定时重试同一冻结保存操作，避免重复建档。步行绘图附件本轮仅用于实时展示，不进入 saved-trip-v1；已有公交数据仍按原规则保存。历史只读页不打开地图或补查几何。不要故意制造真实写入故障。

## 3:15–4:30　从历史继续规划

点击“基于此行程继续规划”，新标签页打开，原页面还在。副本带入需求、当次可选输入、停留、午餐、交通方式及用户费用；没有新正式草案，也不自动查询。

把必去停留改为 75 分钟，主动生成。成功后另存为新名称；历史原记录仍只读、不覆盖。若修改日期或人数，费用估算需重新填写，不能自动按比例变成新报价。

结尾：未保存工作刷新会丢失；历史只是旧快照，不代表旅行当天交通、营业、预约或价格已核验。历史只读详情不加载正式地图，副本主动生成新草案后才可打开同批路线。当前没有预算优化、最优路线保证、全天路线拼接或实时导航。

## 独立示例与演示边界

### 可选30秒：旅行资料检索（6D-1）

当前开放范围（6D-2暂缓收尾）：正式能力只保留可追溯资料检索，AI问答按钮/结果已移除，后端问答入口固定停用。RAG问答作为实验实现保留，但质量未达准入要求；不是“回答质量验收通过”。不为演示调用模型。后续7A-1受控单Agent方向只记录，另行授权后再开展。

从工作区点“旅行资料查询（新标签页）”，原草案和费用保持。明确选“上海博物馆东馆”，输入“数字馆还需要预约吗”，点击查询，查看摘要、来源时间、适用提示并打开官方原文。再选“上海自然博物馆”查“化石挖掘是现场还是微信预约”，展示同页差异而非替馆方裁决。查询“迪士尼烟花几点”演示未收录状态。返回原标签，核对草案、地图和费用还在。

说明：这里是**真实官方资料＋本地中文词法检索**，不是AI答案；不访问千问、不联机抓取网站，不会调整行程。历史公告不能直接证明现在可免预约，检索排名不是可信度或入场保证。收录清单、冻结评测和已知误命中见 `docs/KNOWLEDGE_6D1.md`。

首页页脚链接打开 `/demo`。这里保留旧 `/trips/plan` 固定两日 Mock 组合示例与真实地图联调；必须主动提交后才加载示例，真实 POI 和路线还需主动操作。它不是正式草案地图，Mock 时间、费用、天气不用于正式核算。

旧示例的活动绑定与单段道路路线可在该独立页面另行演示，不混入正式地图状态。正式页只展示当前日期实际采用的单次交通，未采用预览不会改变其路线。单机 SQLite 存档没有账号隔离；未实现自动保存、多用户权限、营业／预约核验。
