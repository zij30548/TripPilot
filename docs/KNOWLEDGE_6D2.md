## 数据边界和交互

- `POST /knowledge/answer`只接收`venue_id / question / request_id / corpus_version / corpus_hash`，拒绝额外正文、URL、模型名、提示等字段。最大请求4 KiB、接收截止5秒。
- 后端读取已校验本地库，检查版本/hash，按同问题/馆区重跑原BM25、最多5片段。版本过期409要求重新检索，零上游；无匹配直接`insufficient / local_no_match`，模型和用量为空，零上游。文件损坏/服务异常返回失败，不冒充资料不足。
- 模型输入仅含问题、明确馆区、匹配片段及类型/日期/适用范围。整理摘要与短摘录分开，不含任意客户端资料/URL。系统提示独立，问题和资料中的角色声明/命令是不可信数据。
- 复用`QwenClient.generate`、配置白名单、鉴权隔离、安全错误和取消。非思考、非流式、一次20秒截止、1024输出token及原输入/响应限额；前端25秒。无重试、输出修复调用或第二评分模型。
- 最多3条事实、每条180字符、必须有本次E1..E5证据。answered无missing；partial有事实和missing；insufficient无事实、missing非空。missing仅允许`not_in_materials / live_availability / weather_not_collected / current_applicability / conflicting_materials / other_venue`，无自由事实字段。
- 后端映射真实chunk/source/URL/版本/hash；前端核对完整请求与检索快照。未知引用、跨馆区、旧版本、空引用、额外字段、超限、截断均整条拒绝，不删错字段挽救输出。最后补修也拒绝`[1]`、`【1】`等行内数字引用，以及未包含于本条证据集合的E数字。此有限格式检查不是自然语言引用或数字/日期的完整语义检查。
- 页面保留资料独立阅读，提供回答状态、片段锚点、官方原文链接、日期/适用性及版本折叠区。历史不证明当前，未知更新时间不阻止有限转述，摘要不冒充官方原话，资料缺失不等于不存在。
- AbortController+单调版本隔离旧成功/错误/finally、A→B→A、重复点击、取消和卸载。改馆区/问题、开始新检索、新资料绑定即取消清空旧回答；失败和取消保留当前资料。重新生成仅主动点击。
- 打开/编辑/检索完成/看引用/打开来源均不自动调用模型。正式需求、排程、费用、地图、预览、存档及数据库不变。
