## 长期目标：国内旅行规划助手

帮助个人及小团体把旅行灵感、想去的地点、时间和费用约束转化为可解释、可调整、可保存的方案。用户掌握地点确认和方案采用权；AI 降低表达与查找成本，程序和真实来源承担事实核对。

长期方向包括：选择国内目的地；更长时间的旅行；从照片识别可能的景点，再到从短视频发现多个地点；用户核对真实 POI 并明确确认后，才将地点用于规划、调整和保存；最终支持跨城市与多个住宿点。

**当前仅开放上海、杭州、北京、广州、成都、西安六城单选，1～7 天、单住宿；全国开放、进一步容量扩展、批量视频多地点发现及跨城多住宿均未实现。当前范围不是长期永久限制。** 单照片及视频选中一帧只提供线索，须用户核对并确认真实POI，不保证任意图片准确定位。地点容量仍为6必去／本次3可选，不保证每天有活动。各能力的真实验证范围不同，成都公交完整样本尚未通过。后续天数／容量、批量视频与阶段编号仍待细化，依赖与优先级见[ROADMAP](ROADMAP.md)，不能一次性据此实施。

### 正式工作区

- 首页确认 `TripRequest` 后直接进入共享 `PlanningWorkspace`；历史副本复用同一工作区。进入不等于生成，不调用旧 `POST /trips/plan`，不自动查询候选、交通、天气或模型。
- 上海／杭州／北京／广州／成都／西安单城 1～7 天，每天同一住宿参考点往返；住宿需用户确认，不等于酒店预订。必去最多 6 个，按确认顺序；可选来自有效候选池未排除的前 3 个，必去全排入后每日尾部至多补充 1 个；无必去时也可仅试排可选。不均分或虚构活动填满七天。
- 整份草案选择步行或所选城市公交／地铁参考，不自动比较、混选或失败兜底。使用真实路线秒数统一向上取整成分钟；独立停留设置、午餐不可占用窗口、等待和完整返程。无路线、未安排和空白日期明确显示。
- 主动查看正式每日地点／编号／双向 Marker，以及当天时间轴中一段实际交通的同次查询几何；不拼接全天路线、不为地图补查。未采用的预览不进入正式地图。
- 独立天气查询与用户标注的游览方式关联检查；主动排除预览、新旧对比、取消或确认采用。天气不自动更换地点或重排行程。
- 费用只读当前正式时间轴与用户估算，整数分累计、全部旅客口径；未知不是零，预算差额不是自由余额。调整两侧共用用户估算；费用不改变排程或采用资格。
- SQLite 新正式行程保存 `saved-trip-v3`；v1/v2 继续严格限定原 1～3 天与原重放含义，不能冒用旧版本存七天。从历史创建新会话，恢复输入而不是把旧结果当新成功，主动重新生成后另存 v3。旧 v1 缺少行政归属，继续规划须重新搜索确认住宿／必去，旧可选不当作有效输入。事务式编辑取消保留当前工作；确认日期／人数变化清空费用，切城清除全部旧城依赖及费用。

## 已确认的Agent演进方向（规划，尚未实施）

优先完成现有版本受控上线与一周内演示，release-1F仍仅是部署包准备。随后按**多轮澄清 → 工具／Skill注册 → 有界执行 → 持久任务恢复 → 长期偏好与可执行旅行约束 → 有业务依据的专业协作**推进；评测、追踪、权限、费用与故障治理贯穿各阶段。详见[AGENT_EVOLUTION](AGENT_EVOLUTION.md)，各阶段均需单独授权和验收，不取代[ROADMAP](ROADMAP.md)中的城市、容量、媒体、多住宿及排程优化方向。

简单操作继续直接执行确定性工具或一次工具选择；信息不足先澄清，只有受支持的多步任务才进入有明确调用／时长上限的循环。首个拟建完整闭环仅为查询某日安排、核对费用、多轮确认一个可选地点、生成排除预览、暂停后继续并明确采用。当前7A-1不是这一闭环：它没有跨轮上下文或工具结果回送；v3最终存档也不保存任务步骤、待确认状态或长期偏好。

当前正式草案／候选／预览／费用主要由前端内存控制，采用是同步一致提交；服务端存档幂等不等于跨刷新恢复。未来须另建白名单式持久工作副本与任务／步骤／尝试状态、权威版本和确认收据，而不是序列化整个React状态或放宽旧存档契约。已发送但结果不明的外部调用不能盲目重跑；恢复前核对身份、数据时效、草案与依赖版本，保存保留原操作标识及冻结内容。

用户原始表达、已确认的本次需求／长期偏好、模型推断必须分开；推断只能待确认，不能自动变成硬约束或长期记忆。本次明确要求优先于默认偏好；系统尚不支持的节奏、步行限制、预约等约束仍须标为未执行，不因为理解了文字就承诺已满足。

专业协作拟采用协调者＋受限专业子Agent＋确定性校验，统一需求版本、任务额度及正式提交入口。先确认真实机票／酒店数据、授权与条件，再做研究比较；预订支付另立阶段，不能用住宿POI冒充报价／库存。多Agent不是模块拆分的必然结果或其他产品方向的前置；数据库、编排与检索框架按实际问题另行选型。知识库生成式问答继续停用，旧评分与台账不改。
