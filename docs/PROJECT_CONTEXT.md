本文件描述产品定位及当前边界，不是新增功能授权。2026-10-16 在 `f25362ee76958580c0f86c2dcbde96191be7e387` 基线上完成 media-1 离线评审标准与新样本冻结：8输入／7原图，逐张检查并披露同源关系，本轮模型和业务调用0；保留此前城市别名回放结果与原质量失败，识别质量仍未通过。未修改模型提示或输出契约，不进入视频。若 HEAD 继续变化，先核对代码及 [PROGRESS](PROGRESS.md) 的最新摘要，不依据旧聊天回退。

## 长期目标：国内旅行规划助手

帮助个人及小团体把旅行灵感、想去的地点、时间和费用约束转化为可解释、可调整、可保存的方案。用户掌握地点确认和方案采用权；AI 降低表达与查找成本，程序和真实来源承担事实核对。

长期方向包括：选择国内目的地；更长时间的旅行；从照片识别可能的景点，再到从短视频发现多个地点；用户核对真实 POI 并明确确认后，才将地点用于规划、调整和保存；最终支持跨城市与多个住宿点。

**当前仅开放上海、杭州、北京、广州、成都、西安六城单选，1～7 天、单住宿；全国开放、进一步容量扩展、视频及跨城多住宿均未实现。当前范围不是长期永久限制。** 单照片入口已实现但质量未全部验收通过。地点容量仍为 6 必去／本次 3 可选，不保证每天有活动。各能力的真实验证范围不同，成都公交完整样本尚未通过，详见下方限制。后续天数／容量、视频上传限制和阶段编号仍待细化。依赖与优先级见 [ROADMAP](ROADMAP.md)，不能一次性据此实施。

## 当前可用及已验收范围

### 正式工作区

- 首页确认 `TripRequest` 后直接进入共享 `PlanningWorkspace`；历史副本复用同一工作区。进入不等于生成，不调用旧 `POST /trips/plan`，不自动查询候选、交通、天气或模型。
- 上海／杭州／北京／广州／成都／西安单城 1～7 天，每天同一住宿参考点往返；住宿需用户确认，不等于酒店预订。必去最多 6 个，按确认顺序；可选来自有效候选池未排除的前 3 个，必去全排入后每日尾部至多补充 1 个；无必去时也可仅试排可选。不均分或虚构活动填满七天。
- 整份草案选择步行或所选城市公交／地铁参考，不自动比较、混选或失败兜底。使用真实路线秒数统一向上取整成分钟；独立停留设置、午餐不可占用窗口、等待和完整返程。无路线、未安排和空白日期明确显示。
- 主动查看正式每日地点／编号／双向 Marker，以及当天时间轴中一段实际交通的同次查询几何；不拼接全天路线、不为地图补查。未采用的预览不进入正式地图。
- 独立天气查询与用户标注的游览方式关联检查；主动排除预览、新旧对比、取消或确认采用。天气不自动更换地点或重排行程。
- 费用只读当前正式时间轴与用户估算，整数分累计、全部旅客口径；未知不是零，预算差额不是自由余额。调整两侧共用用户估算；费用不改变排程或采用资格。
- SQLite 新正式行程保存 `saved-trip-v3`；v1/v2 继续严格限定原 1～3 天与原重放含义，不能冒用旧版本存七天。从历史创建新会话，恢复输入而不是把旧结果当新成功，主动重新生成后另存 v3。旧 v1 缺少行政归属，继续规划须重新搜索确认住宿／必去，旧可选不当作有效输入。事务式编辑取消保留当前工作；确认日期／人数变化清空费用，切城清除全部旧城依赖及费用。

### AI：已经接入，但职责受限

media-1 的视觉能力独立于下列三个行程功能：仅显式上传一张照片，`photo-landmark-v2`的possible恰好一条可能名称／城市，uncertain/unrecognized空候选；不再返回basis自由依据，固定提示“模型线索，未经核实”。不输出POI ID或坐标。照片专用解析仅接受六城中文／官方中文及Shanghai、Hangzhou、Beijing、Guangzhou、Chengdu、Xian／Xi'an／Xi’an，首尾空白及英文大小写可不同；原始文本保留。未知／混写／跨城仍不放行，不扩高德归属校验、不视为POI认证。匹配后必须主动搜索、预览并确认真实POI；只加入需求编辑中的必去，取消整次编辑不改变正式工作。图片内文字不可信，结构合法不能证明识别正确。两轮独立12/12均用尽；原4/8与保守版清晰6/6、拒识3/4、Chrome1/2均不改。英文门控现以历史回放＋真实高德链路修复，非新实时识别；新的局部分层标准与样本已单独冻结，见[MEDIA_1_EVALUATION_STANDARD](MEDIA_1_EVALUATION_STANDARD.md)，不重评旧api02；**识别质量仍未完成验收**，详见 [MEDIA_1](MEDIA_1.md)。删除依据字段不是证明依据质量已改善。

1. 行程解读：模型选择当前正式草案事实 ID，程序核对引用与前提，渲染内容并固定展示关键限制。
2. 自然语言调整：只支持请求排除一个当前已安排的可选地点；歧义／多动作／不支持需澄清或拒绝。程序生成预览，用户采用才改变正式状态；模型不直接写行程。
3. 7A-1 只读查询：原生 `tools/tool_calls` 选择指定日期、全程费用或有限原因澄清；后端校验，前端读取与请求版本绑定的本地草案／费用。每次最多一个工具调用、一次模型请求，无循环、重试或追加总结。

7A-1 **已在上述限定范围收口**，不等于自主 Agent 或广泛自然语言泛化完成。原版本 8 次真实 API 失败、修复版原输出离线重放 8/8、修复版真实 Chrome 续验 4/4 分开保留；累计 12/12，无剩余额度。此前各阶段台账仍有效，不能把换对话、重启、换阶段视为新调用授权。

## 实际技术与数据边界

- 前端：Next.js 16.3.3 App Router、React 19.2.8、TypeScript、Tailwind 4；本地 Hook/ref + fetch，无全局状态库。修改前阅读 `frontend/AGENTS.md` 和该版本本地 Next 文档。
- 后端：`pyproject.toml` 要求 Python >=3.13（不是早期规划的 3.12）；FastAPI、Pydantic/pydantic-settings、httpx、SQLModel。依赖由 uv.lock 和 package-lock.json 管理。
- 图片：仅新增锁定Pillow12.3.0；原始二进制请求有界读取，不用multipart临时文件。5MiB／2000万像素／静态JPEG-PNG-WebP，转正、去元数据、长边2048后发送；单进程1张、上传10秒、模型操作20秒、前端35秒。无URL下载、数据库照片、日志Base64或模型自动重试。独立 `QWEN_VISION_MODEL=qwen3-vl-plus`，其JSON Object+服务端严格Schema不改变原AI契约。产品并无全局账号配额系统。
- 外部数据：高德 POI、步行／公交、选定城市天气；浏览器 JS API 2.0 和现有限定代理。`shared/destinations.json` 统一六城及区县白名单；Python 加载校验与 Python→TypeScript 测试检测允许值漂移、重复和明显归属矛盾。归属核对上游 citycode/cityname/adcode，不以名称或客户端声称证明真实性，不增加验证请求。千问百炼北京地域配置仅在服务端，默认 Flash 快照；Plus 等历史研究模型不等于正式默认配置。
- 排程：后端纯规则函数与有界路线采集分离。共享 `planning-limits.json`：七天含可选最多 41 条逻辑边（必去17＋尾点／可选24），实际启动不同路线仍至多29条／58次上游尝试，必去优先、固定顺序分配，复用及同点不占新查询。两阶段共享并发3、至少0.4秒启动间隔和20秒搜索截止。预算／截止未启动记 `budget_exhausted`，不伪造可行性结论；取消清理可能增加返回时间，节流不是账号级限流。
- 存档：`backend/data/saved-trips.sqlite3`，请求级 Session，唯一保存操作标识及幂等冲突校验；首次存档访问初始化表，不是迁移平台。读取不重新查询上游，不支持覆盖／删除／自动保存或账号隔离。
- `saved-trip-v1` 保留原字段／重放语义；v2 增加目的地与地点归属，仍投影到原三天核心。v3 显式投影到七天核心；不放宽额外字段，不改旧表、记录或时间。各版保存确认需求、实际排程请求／规范化结果及相关费用文本；不保存 AI、天气、临时预览、完整候选历史、地图状态或步行附件。v3 餐饮对应全部七个实际日期，包括空日；2 MiB 及几何上限不扩张，公交规范数据保留。上游与时区 `Asia/Shanghai` 不随展示名替换。
- 正式草案、预览、恢复输入和历史只读结果必须分开。失效操作同步 abort 并递增版本，晚 success/error/finally 不可恢复旧状态；确认采用原子更新输入与结果。存档验证是内部一致性检查，不是认证客户端数据来自高德。

## 当前尚未实现／不作承诺

- 全国城市选择、超过七天或扩展地点容量、多照片／视频、可选池媒体导入、跨城及多住宿。单照片代码已实现，但不能承诺可靠识别或全国准确率。
- 海外旅行规划、自动支付、火车票／机票购买；这些不属于当前国内规划主线的已实现能力。
- 全局最优排程、自动交通比较、预算优化、营业／门票／预约核验、天气自动重排。节奏偏好暂不参与排程，不想去文字未自动语义过滤。
- 公交旅行日期与具体出发时刻的班次保证、实时到站、导航或全日路线拼接。
- 登录、用户数据隔离、公网上传管理、跨用户限额、自动备份、云同步、可直接上线的部署与运营体系。
- 自主循环、多 Agent、LangGraph、MCP、向量检索；没有把它们作为实现当前产品的前置条件。

## 不变原则与文档读取

住宿与必去需用户明确确认；可选需展示本次试排名单并由用户主动生成，不要求每个可选逐一确认。照片线索也须由用户核对并确认真实 POI；搜到同名POI不证明照片匹配。模型不编造交通耗时、价格、天气、营业或预约事实。来源、查询时间、未知项、失败和未安排原因须可追溯；历史时间不能被重新打开或编辑刷新成新数据。

duration-1 在杭州实测七日步行、第四天实际游览、后续空日、七天天气部分覆盖、预览取消／采用、七日费用、v3 保存刷新／副本主动再生及四日公交。没有真实满载跑遍六城，也没有长行程真实模型调用；最大规模和异常用受控测试。详见 [DURATION_1](DURATION_1.md)，不覆盖上述目的地阶段失败。
