# TripPilot 产品与架构上下文

更新：2026-10-23。本文件只维护当前事实和长期定位；实际交付、失败与停止点见[PROGRESS](PROGRESS.md)，旧交付记录见[历史导航](archive/README.md)。历史报告中的“当前”只表示其当时状态。

## 产品定位与长期目标

TripPilot 是面向个人及小团体的国内旅行助手：通过对话说清需求，把想去的真实地点、时间和预算约束转化为可核对、可调整、可保存的行程。用户掌握地点确认、方案采用与保存权；不是通用聊天、客服或自动预订产品。

长期方向是国内目的地选择、更长行程、照片／视频发现地点，以及跨城、多住宿规划。媒体只提供线索，须核对真实POI后参与规划。**当前六城、1～7天和单住宿是版本边界，不是永久限制；未来方向不是已实现能力或一次性授权。**

## 保留的真实规划能力与限制

- 六城单选：上海、杭州、北京、广州、成都、西安；单城1～7天、一个住宿参考点、最多6必去／本次前三有效可选。必去原顺序、每日住宿往返、停留与午餐避让；不均分活动，空日和部分安排有效。
- 高德提供已确认POI、步行／公交参考与天气；程序排程，不由模型编造耗时或整份行程。不保证最优路线、旅行当天班次、营业、预约或门票；成都历史公交样本仍有`data_error`，不能宣称其完整公交草案已真实验收。
- 地图按正式草案当天实际访问与单段同次查询几何展示；未采用预览不影响正式地图，无几何不补直线／补查。天气按覆盖日期分别解释昼夜，未知不当晴天。
- 费用用实际时间轴逐次交通加用户估算、整数分累计；未知不是零，已知小计不是完整总价，预算不改变排程或采用资格。预览保留原方案，明确采用后才提交；保存使用冻结内容及幂等标识。
- 照片／视频选中单帧只给一个可能名称／城市或拒识，再主动高德搜索、预览并明确确认加入必去。城市别名和同名POI不证明视觉身份；限定小样本通过，不代表六城／全国可靠识别。媒体不入存档，不做批量视频多地点发现。
- 旧行程解读、自然语言单可选排除、只读日期／费用查询按需使用。7A-1原生`tool_calls`是单次选择，不是循环；其原API失败、修复离线回放与Chrome结果分别保留。

具体规则／真实证据分别见[DESTINATION_2](DESTINATION_2.md)、[DURATION_1](DURATION_1.md)、[MEDIA_1](MEDIA_1.md)、[MEDIA_2A](MEDIA_2A.md)、[MEDIA_2B](MEDIA_2B.md)、[7A-1](ITINERARY_QUERY_7A1.md)。历史次数和失败不在当前摘要重复重算。

## 实际架构与状态边界

- **前端**：Next.js 16.3.8 App Router、React 19.2.8、TypeScript、Tailwind4；Hook/ref、fetch、AbortController和单调版本／身份epoch。浏览器固定同源`/api/*`与地图代理；目标只由Next可信服务端配置决定。
- **后端**：Python≥3.13、FastAPI、Pydantic、httpx、SQLModel；源码按`api/agents/core/tooling/memory/monitor/evaluation/skills`组织，旧app源码移动而非维护双份；配置和领域规则仍保持原边界。`shared/destinations.json`与`planning-limits.json`统一容量，不靠放宽历史契约迁移。
- **AI**：当前运行路径为百炼北京地域，聊天有界反馈使用既有Flash，照片独立`qwen3-vl-plus`；旧独立AI接口仍单次有界，没有Anthropic或第二供应商。选装核心另有受计量的Embedding与单次Judge，未用于本轮直接工具执行、未真实调用；新runtime已显式接线但默认／现有运行服务未启用。本轮旅行候选与此前dialogue-v2均零真实调用；历史迁移独立授权8次实际5次：首版1结构失败，严格index兼容修复后3个剩余请求共4次通过；高德2POI＋2步行。不同版本分开，不与旧9/12拼分，未用次数不自动追加。
- **本机新版存储**：独立MySQL承载浏览器工作区、会话、对话、意向、存档和持久业务额度；沿用原owner／会话表兼容旧数据，不新增表、不删除旧账号／邀请。地点副本为`chat-places-storage-v1`，运行仍不自动加表，旧库、身份锚及所有尝试状态不改写；新工作区不回退SQLite。
- **存档**：新正式快照v3支持七天；v1/v2严格保留原1～3天字段与重放含义。快照不是会话、任务恢复或长期偏好；媒体、AI、天气、地图状态与临时预览不入存档。历史打开不刷新原时间或重新核验。
- **工作区与测试**：当前正式应用不挂载旧`/auth/*`，浏览器自动建立独立匿名工作区；CSRF／Origin、服务端owner、版本epoch、取消与持久全局额度仍有效。清Cookie可建立新工作区，因此单工作区额度不再等同于实名／账号抗重建限制；全局硬额度不重置。3110直接使用，无需8810或邀请码；旧3104保留旧运行环境，不自动同步。
- **权威状态**：MySQL持有服务端聊天、地点、任务回执和明确偏好；`assistant-storage-v1`须显式复制到空目标，运行不DDL。新聊天无面板复用原规划控制器；本地程序消息、正式草案、费用和预览未变成服务端持久恢复。任务回执只记录服务端完成的提议／执行部分，不证明浏览器后续已经执行，也不授权重放未知调用。正式草案、预览、历史与恢复输入保持分开。

存储／迁移与运行限制详见[MYSQL_REGISTRATION](MYSQL_REGISTRATION.md)、[CHAT_1](CHAT_1.md)、[RELEASE_1C](RELEASE_1C.md)、[RELEASE_1E](RELEASE_1E.md)。业务次数额度不是精确人民币上限，浏览器直连SDK／底图和入口资源保护另计。

## 当前未完成与后续依赖

本轮38项聊天动作接入已做受控检查，真实模型／高德调用0；新动作的自然语言理解、选择正确性及广泛多轮语义仍未真实验收。此前迁移有固定澄清／需求工具反馈／主动搜索及上海真实步行费用存档链证据；不是旧chat-1改判，也不是当前全部聊天动作或六城重验。生产新聊天数据备份／恢复、线上MySQL切换仍未完成；用户报告的旧版HTTPS登录不等于新版生产迁移，代码推送不自动更新服务器或切库。

已有有限工具注册、可信Skill和有界原生工具反馈；明确偏好可保存／撤回，持久任务状态可读回但不是完整暂停续跑。词法角色路由不是并行专业多Agent，进程内Monitor不是生产语义评分；真实MCP、完整工作区恢复、向量记忆和专业协作未实现。机票／酒店先核对数据授权，研究比较与交易分阶段。

全国开放、更多天数／地点容量、批量媒体、跨城、多住宿、自动优化及完整公网运维也未完成。模型理解“轻松”等偏好不等于排程已执行；原话、已确认偏好与模型推断不能混同。
