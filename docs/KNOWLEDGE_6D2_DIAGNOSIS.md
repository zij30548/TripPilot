## 3. 最小候选：整块选证据，程序呈现

**A基线**保持生产 `knowledge-answer-6d2-fix-v3` / `answer_payload` / `render_answer` 原样。**B仅在离线工具中**实现 `knowledge-evidence-selection-offline-v1`，不挂接口、不替换页面。

1. 使用同一馆区、同一问题、同一次本地检索的相同顺序top5、相同文档背景。B把A的`curated_summary_sentences`原样连接回该主题片段的完整`section.summary`；没有新增、删掉或重写证据。
2. 最小安全单元是**现有完整主题片段**，不再按句号、分号、但/除外/或切成可选事实。短摘录随整个单元展示，不能单独选择一句“散客免预约”丢掉例外。整块中可能有背景服务信息，宁保留明确范围，也不做自动条件拆解。
3. 模型只输出最多6个`subquestions`，每项 `{question_span, evidence_ids, missing}`；question_span必须为原问题的逐字片段，每项最多5个本次E ID、4个既有缺失代码。不接受自由事实正文、URL、额外字段或模型指定状态。
4. 程序按ID取原片段、原日期、版本/hash与URL；展示“**整理摘要（非官方原话，完整主题单元）**”和单独“来源短摘录”。共享单元正文只展示一次，保留各子问题对应关系。文档时间仍标背景，不自动写成每条服务的有效期。
5. 缺失代码渲染成无引用的固定提示，与资料事实区分；有证据无missing→answered，有证据有missing→partial，只有missing→insufficient。这只是组合一致性，**不校正模型漏标/错标的missing**。
6. 整块内容不被改写，降低日期、数值、主语和例外被加工的风险；代价是更长、较少概括、部分伴随信息冗余。它更接近“按子问题选择的证据式答复”，不是同样自然简洁的自由答案。正式产品是否采用这种形式仍待对照与授权。

工具不按题号/完整问题/固定答案分支；题号只用于从原评测选择离线输入，标签和required不发送模型。原问题逐字片段可以包含恶意命令，因此**来源合法不等于合法子问题**，仍须在评测中检查。

### 结构检查不能证明的事

三类指标必须独立：

- 引用存在性：ID/馆区/版本/hash对应当前候选集，只证明“引用到了这个片段”。
- 事实改写风险：B的正文逐字符来自完整整理摘要，能验证未改写；不能证明人工摘要完全忠于官网、资料当前有效或没有来源自身冲突。
- 证据选择正确性：是否直接支持该子问题、覆盖全部合法子问题、missing是否必要、冲突是否被隐去。**需要逐项人工评审，结构检查无法证明**。

受控测试特意保留三个“合法结构但语义不对”的例子：给实时名额问题选择静态预约片段、只处理借车漏天气、把越权命令片段当子问题。工具照样能通过结构；这些不是质量通过样例，不得在汇总中充当B改善证据。
