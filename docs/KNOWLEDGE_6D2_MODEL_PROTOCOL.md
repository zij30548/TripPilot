## 持久计数、观测和停止

- 唯一固定CLI目录 `trippilot-evidence/6d-2/model-selection/`；发送前flock/flush/fsync预记。操作唯一标识包含batch、case、请求模型快照、repetition。重启不能重发预记操作；没有单题/额度/路径/模型/恢复覆盖参数。无法落盘不发送，孤立attempt暂停。
- 普通语义、漏答、选材、missing、结构/引用、拒绝/空内容/截断失败保留后继续预定操作，不修补、不重试。配置/不支持参数或模型、鉴权/额度/限流、网络超时/取消、计数/冻结版本等执行异常则暂停，不自动恢复或换别名/地域/思考模式。
- 请求模型与上游返回model分开记录；有界被动读取同一响应的模型字段与用量，不额外读取/发送、不给原传输扩大容量。只记录安全模型标识，不保存原始网络body/header；服务报告的别名不证明内部部署快照。明显不同模型标识作为执行异常暂停；缺失标识记未知。
- 若请求失败前已发出/取消，计次。到20次立即停止；未完成则报告缺项，不补成成功。没有浏览器/连通性/调试调用。

无论结果如何都不正式替换。五题是已知诊断题，每题两次不足以证明泛化；更优模型最多推荐进入**另行授权**的完整复验，或建议两者均暂缓。不得自动扩题或追加调用。
