## 可重建索引与接口

在 backend 执行（均离线，`-B` 不改原 Python 缓存）：

```sh
.venv/bin/python -B -m app.services.knowledge
.venv/bin/python -B -m app.services.knowledge --evaluate dev
.venv/bin/python -B -m app.services.knowledge --evaluate validation
```

第一条严格校验语料并重建**进程内索引**，输出语料/资料哈希、规模及来源清单；不追加条目、不写业务数据库。在线首次查询同样构建只读索引，随后本进程复用；更新语料需要人工复核、递增版本并重启服务，无后台抓取或自动刷新。资料/章节 ID 唯一，重复 URL/ID 拒绝；未知版本、非法日期、非白名单链接、跨馆区 ID/URL 关系拒绝。语料128 KiB上限、6–10份资料，每份1–12节，最多120片段。按人工核对的标题/主题段落成块，超过360字摘要拒绝，不按字符硬切，避免拆散人群、日期、例外和冲突说明。

`POST /knowledge/search` 只接收 `{venue_id, question, limit}`：馆区三值枚举，问题2–160字符、无控制字符、两端无空格（前端先trim），limit默认5且1–5。请求体4 KiB、读取截止5秒；拒绝额外字段、重复JSON键、非有限值、无效类型。前端10秒截止，单次请求，无重试；主动取消、输入修改、卸载立即取消并递增版本，旧success/error/finally与旧取消回调不能覆盖新查询。

返回 `knowledge-search-v1`：完整请求回显、馆区、语料版本/哈希、规模、matches/no_match，最多五个包含章节、短摘录、摘要、资料ID/URL、内容哈希、全部日期和适用说明的片段。前后端均严格校验，前端还核对请求回显、排序、唯一引用和六个白名单URL/馆区。422/413/408/503为安全错误，不返回原异常。查询只读本地内容，无高德、千问、天气或存档调用。

方法 `cjk-bigram-bm25-v1`：Unicode NFKC与小写、少量显式同义词、去泛词及场馆名称，再对连续中文取相邻双字片段，英文/数字取词；**不是按空格分中文**。在所选馆区内计算BM25（k1=1.2、b=0.75），分数降序、相同分数按chunk_id稳定排序。未共享词项返回无结果。无向量/分词框架和新依赖。匹配词与分数用于追溯，不展示可信度百分比，不把排名当现行规则判断。
