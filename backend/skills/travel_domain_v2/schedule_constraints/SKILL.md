# schedule_constraints

触发：生成草案、读取某日、修改停留、午餐、交通模式或每日窗口。

流程：读取当前确认需求和真实地点；日期不能唯一映射时先澄清；展示规则修改及失效关系；用户主动生成才调用原排程器；按时间轴报告已安排、未安排原因与空日。

输出：当前日期工具结果或待执行设置提议，保留必去原顺序、每日住宿往返、午餐避让和交通查询时间。

禁止：另写排程算法、均分或重复地点填空、伪造路线耗时、静默转步行、跳过未排必去、承诺路线最优及旅行当天运营。

程序硬检查：六城单城、1～7天、单住宿、六必去／三可选及原路线上限、交叉重放、秒转分钟、当前草案版本。无几何不等于无有效交通，但无必要交通数据不得捏造成功。
