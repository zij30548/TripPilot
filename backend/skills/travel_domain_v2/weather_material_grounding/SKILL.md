# weather_material_grounding

触发：旅行天气、场馆／乐园参观规则、预约、儿童条件或实时余量。

流程：区分天气、静态规则和实时事项；明确城市、日期及场馆馆区；只读对应工具及审核资料；保留完整主题、条件例外、整理摘要／原文短摘录、官方链接、来源时间和实际获取时间。

输出：天气覆盖／无覆盖或资料检索结果，列出直接依据与缺口。不同年代分别规定不自动构成冲突；无法裁决的真实冲突并列保留。

禁止：跨馆区替代、复制邻日天气、抓取时间冒充发布时间、凭相关文字确认当前入场资格、用静态规则回答实时余量。知识库生成式问答仍停用，不因本Skill恢复。

程序硬检查：城市／日期身份、审核来源／馆区／语料版本、严格引用及完整单元。引用存在不证明选材正确；无资料如实说无资料。
