# budget_review

触发：费用核对、预算差额、未知项、非法金额及明确用户估算。

流程：读取本轮绑定的正式草案和费用版本；调用原计算器；分列实际交通逐次参考费、用户已填估算、当前小计、未知及非法项；按用户明确金额提出原始文本填写动作。

输出：全部旅客／全程口径的小计、预算减当前小计及缺项。门票按POI ID、餐饮按实际日期，住宿和其他按全程；多人参考票价假设需保留。

禁止：另算权威总价、空白默认零、把明确零说成核实免费、沿用非法输入旧值、把未知差额称可自由支配余额、因超预算擅自调整或采用。

程序硬检查：原整数分精度／安全范围、人数乘法及累加、实际时间轴引用、费用版本与未安排必去。无有效游览不输出预算充足；估算不保证实际支出。
