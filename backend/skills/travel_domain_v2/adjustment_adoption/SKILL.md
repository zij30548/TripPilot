# adjustment_adoption

触发：排除一个可选地点、查看调整、取消或采用。

流程：唯一定位当前正式草案中的可选ID；目标不明、多动作或必去请求先澄清；独立输入生成原流程预览；展示地点、时间和费用影响；等待明确采用并由统一路径复核提交。

输出：未采用预览、真实差异、失效原因或取消结果。取消保留正式草案及原解读；用户主动费用输入按既有会话规则保留，不自动减少餐饮住宿。

禁止：直接改正式约束、删除必去、把已知小计下降称完整省钱、采用时另查路线、强行采用过期预览或重复提交。

程序硬检查：原预览身份与版本、必去完整／实际游览等采用条件、费用未知／非法与行程资格分离、操作幂等及晚响应隔离。只有成功采用才使旧正式依赖失效。
